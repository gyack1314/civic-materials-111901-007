# 本地来源契约

GET /catalog 返回原件入口，publication_year 是出版年而非观测年；phase=1 公开局部勘误记录，corrects 指向年鉴编号。每条记录可有 pdf 与 workbook 两种载体，声明与注释在原件内部，没有独立答案表。
城市代码 C01、C02 对应合成城市城甲、城乙，P00 为省合计；其地理关系由原件行标签表示。指标名“终端能源”，2023 与 2024 两列是观测年。原件用横跨列的合并表头、续表与页脚注释，单位注释必须按其适用列理解。符号 0 表示零，空白为未刊载，— 表示不适用，… 表示缺报。原值需原样保留，脚注上标不是数值部分。
更正记录仅针对明确列和城市，原件分别声明替换范围及新单位。PDF 页码从 1 开始，矩形位置以 PDF 点数、左上角坐标为准；工作簿证据用表名与单元格地址。其他数据不得因一处更正而被默认撤回。

演练来源由 Python 标准库 HTTP 服务启动，默认端口 8765。GET /health 可查询来源时间与阶段；POST /__admin/advance 接收 seconds、phase 推进本地情形；GET /__admin/log 回查实际请求。这些控制只供操作员调试来源，不能替代产品从正常入口取得资料。来源进程重启会清空其演练状态；采集端自己的保存目录由产品独立管理。
